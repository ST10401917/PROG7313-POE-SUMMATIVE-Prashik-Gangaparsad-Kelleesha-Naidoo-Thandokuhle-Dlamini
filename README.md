Welcome to the KTP Budgeting App!

What is the KTP Budgeting App?
The main purpose of the KTP Budget Tracker App is a personal finance management app which is designed to help anyone to monitor and control their everyday spending. The app allows users to record their expenses, organize them into categories, set monthly spending goals, track their financial activities over time and reward-based motivation. 
Our app also uses Firebase Authentication to ensure secure login and registration, and Firebase Realtime Database to store and retrieve user data in real time. This ensures that user information is saved securely and updated instantly across the application.

Basic Features of the app:
•	Log and categorize daily expenses 
•	Set minimum and maximum budget goals 
•	View past spending records 
•	Analyse spending trends through charts 
•	Receive motivational rewards for financial discipline 
•	Access a chatbot assistant for guidance and FAQs

Special features of the app:
Chatbot 
The application includes a chatbot feature designed to assist users with common budgeting and expense-tracking queries. The chatbot operates using a set of predetermined questions and responses, allowing users to receive instant guidance and support within the application. When a user asks a question that matches one of the predefined queries, the chatbot provides a relevant answer to the question.

Badge Rewards system
The reward system was implemented to encourage users to manage their finances effectively. Users can earn achievement badges by completing financial goals and challenges within the application, such as staying within a budget, reaching savings targets, and consistently tracking expenses. A Rewards page displays each achievement, showing whether it is locked or earned, along with progress bars that indicate how close the user is to unlocking each reward. If a user exceeds their budget or fails to meet the required conditions, the reward remains locked and is not awarded. 

Design Considerations and User Interface (UI) Design
The KTP Budgeting app has 8 screens 
•	Login screen
•	Register screen 
•	Home screen  
•	Expense entry screen 
•	Records screen
•	Report screen 
•	Rewards screen 
•	Chatbot help screen 

The UI design is very clean and very easy to read and understand. The texts, buttons and functions of each page are inside a card layout to make the app look very professional. A bottom navigation bar is used across all major screens to allow quick and consistent navigation between features. This improves usability and reduces user confusion.
GitHub 
GitHub was used as the primary version control system for the development of the budgeting application. It allowed for the code to shared amongst the team members and to be securely stored in the cloud.
GitHub Actions
GitHub Actions was used to introduce continuous integration (CI) into the project development process. This automation tool helped ensure that our application remained stable and buildable after each update was done to the project.
